# Handwritten Character Recognition

## Description
This project uses a neural network to recognize handwritten digits.

## Technologies Used
* Python
* TensorFlow
* NumPy
* Matplotlib

## Dataset
The project uses the MNIST handwritten digit dataset.

## Model
A simple neural network is trained using the MNIST dataset.

## Result
The model achieved approximately 97.57% test accuracy.

## How to Run
1. Activate the virtual environment.
2. Run:
```bash
python main.py
```
